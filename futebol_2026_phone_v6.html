ELO History
How a player's ELO moved, game by game
The Δ for each game is the player's own recorded ELO adjustment for that game (Excel "Ajuste ELO" column) — never estimated. "ELO before/after" are Initial ELO plus the running total of those recorded deltas, so if you edit Initial ELO in the Players tab, the whole trajectory shifts together and stays consistent.

Settings
App data
—
Data is stored locally in this browser (localStorage). Export a backup regularly.
Season
Year
Every page in the app — Records, Rankings, Current Form, Player Stats, and more — shows only this year's games. Switching years never deletes anything; it's just what you're currently looking at. ELO keeps running continuously across years and isn't affected by this, except for 2025, which is a frozen, view-only year that never feeds into ELO.
ELO settings
K-factor
Controls how much ELO shifts per game. Higher = bigger swings. Default is 20.
Eligibility
Min. % of total games
A player needs to have played at least this % of all recorded games to count as "eligible" (i.e. could realistically win the tournament). Used by the "eligible only" toggle on ranking pages and by the Home widgets. Default is 30%.
Backup
Importing a backup replaces all current data.
Import from Excel
Re-import your .xlsx file. This replaces all current data with what's in the file.
Danger zone
Erase all players, games, and stats stored in this browser.
